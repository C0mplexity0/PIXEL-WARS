# PIXEL WARS

PIXEL WARS is a pixel-based browser game with multiplayer and modding support. It comes pre-built with various gamemodes, with in-browser singleplayer as well as multiplayer support through third-party servers.

## Development

To set up a development environment with PNPM:
```bash
git clone https://github.com/C0mplexity0/PIXEL-WARS pixel-wars
cd pixel-wars
pnpm i
```

You can then run `pnpm dev:<package>` to test and develop specific packages (e.g. `pnpm dev:client`).
